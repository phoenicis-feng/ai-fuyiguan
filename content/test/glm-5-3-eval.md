实测 GLM 5.3｜重回开源国模一哥

## 01 先翻译成人话

BASIC CONCEPT / AGENT LOOP
Agent Loop 就是 AI 自己「干活 → 看结果 → 再决定下一步」，循环很多轮，直到把事做完。通俗点就是 AI 学会“自己干活”，不用每走一步都等你指挥。

而长程调度（Long-Horizon）指的就是：为了完成这个目标，AI 要自己能分成很多步、跨很多轮、还得一直记得自己干到哪了。它的难点很在于：第 1 步错了，第 10 步就废，错误会一路滚雪球（漂移 shift）；中间经常没人告诉它对不对，走很远才发现方向错了；干到第 20 轮，还得记得第 3 轮说过的话。

所以长程任务一直是模型的软肋：上下文有限，历史越滚越长，模型要么“失忆”，要么忘了自己为什么在干。以前比“谁答得聪明”，现在比“谁能把事做完”。能把几十步的活稳稳干完、干砸了能自己恢复的模型，才配碰真实业务。

## 02 实测：让 GLM-5.3 自己循环跑

FIELD TEST / GLM-5.3

CASE 01 — 从 0 到 1 复刻《传奇》
让它从 0 到 1 复刻经典游戏《传奇》，主题换成《摸鱼小李》。第一轮跑出来还挺糙的，就是个能动的 demo。但整整循环了 7 轮之后，拿到了能真正玩下去的《摸鱼传奇》：沉浸感拉满，设定完整，等级、天赋、装备、BOSS 一个不少。

![摸鱼传奇游戏截图](/img/test/glm-5-3-eval/game-legend.png)

更带劲的是过程。每一轮它都会回头看原版《传奇》是怎么做的，再接着往下打磨，一轮比一轮完整。

CASE 02 — 闯关 / 消灭怪物
像素消灭怪物、地图打怪、爆装备、升级、装备强化、Boss 一样不少。整个游戏系统机制非常详实完善，效率真的有点夸张。

CASE 03 — 模拟放置experience游戏
把大本营、农田、工厂、电站放置到地图上。最大问题是玩到后期手忙脚乱，每个单元格太多点不过来。

CASE 04 — 红蓝网络攻防
GLM-5.3 在漏洞识别上已追平第一梯队（CyberGym 84.5%，跟 Mythos 5 基本持平）。让我让它分别扮演红蓝两队进行攻防，记录可视化结果出色。

![网攻防可视化](/img/test/glm-5-3-eval/game-legend2.png)
此外还做了侦探推理游戏、探险迷宫游戏。

## 03 没有视觉，但底层是真强

MODEL LIMIT / VISUAL
现阶段 GLM-5.3 最大的痛点：纯文本模型（单模态），没有视觉模型，看不了图也造不出图。别的 AI 在 Agent Loop 时还可以截图查看状态根据截图修正下一步，但 GLM-5.3 做不到。

但视觉之外，它的编程能力和系统架构能力是真的强。做仿《传奇》case：它会自己去找《传奇》相关网站、分析引擎，然后基于这个引擎帮我做，真去研究了参考对象再动手，没瞎写。这活儿放在人身上，得叫“系统架构师”。

## 04 设计 loop 提示词

PROMPT DESIGN / LOOP
翻了 Anthropic《Building Effective Agents》、LangChain《The Art of Loop Engineering》和社区踩坑讨论，总结了五条建议：

STEP 1 — 让它把进度存下来（每轮写进文件，长程任务最容易死在没存档）
STEP 2 — 告诉它要循环，还得告诉它现在第几轮（让它知道自己走了多远）
STEP 3 — 提前说好什么时候停（做完停 / 到最大轮数停 / 你喊停，15–25 轮够）
STEP 4 — 报错是好事，让它带着报错接着改（记下来，下一轮换思路再试）
STEP 5 — 如果要做长程调度，提示词里要明确“你是 Agent，你会多轮循环，每轮先想再做再记录再决定是否继续”

写在最后：GLM-5.3 这次在编程与 Agent Loop 上的效率是真的夸张，六个循环做出完整游戏系统，且审美、架构、攻防都到位。缺的只是视觉，这在纯文本模型阶段可以接受，但未来一旦接上多模态，可能直接冲击第一梯队。
